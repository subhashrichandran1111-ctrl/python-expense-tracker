# Personal Expense Tracker

## Project Overview
A Python-based application that helps users record, manage, search and analyze their daily expenses.

## Features
- Add expenses
- View all expenses
- Calculate total expenses
- Save expenses in CSV format
- Load previously saved expenses
- Track expense dates
- Category-wise expense reports
- Search expenses by category
- Monthly expense reports
- Delete expenses
- Input validation and error handling

## Technologies Used
- Python
- CSV
- OS module
- Datetime module
- PyCharm

## Project Structure
- `expense_tracker.py` – Main application
- `expenses.csv` – Local expense data file

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project in PyCharm.
4. Run `expense_tracker.py`.

- Lists and dictionaries

- Exception handling
